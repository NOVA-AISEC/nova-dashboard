# NOVA operator workspace

The primary user is a control-room operator coordinating campus security at Strathmore. The first screen must answer: what needs attention, where is it happening, and what should I do next?

## Product decisions

- Put incidents, campus coverage, and next actions above explanatory content.
- Use compact navigation with operations first and supporting tools below.
- Use warm neutral surfaces, charcoal navigation, orange primary actions, and distinct severity colors.
- Show source dates and demo status honestly. Existing records describe a sample shift on 28 February 2026; do not imply these are current CCTV feeds.
- Review alerts in an accessible side panel. Acknowledge only new alerts; acknowledgement is separate from validation, containment, or closure.
- Keep role access consistent across links, search, and detail actions.
- Persist local mock acknowledgements and cases, synchronize workspace views, and show action errors visibly.
- Provide filters, sorting, direct case navigation, report intake, and downloadable shift handovers.
- Label the campus map as a schematic. Derive incident counts from the current dataset.

## Readiness

This implementation modernizes the frontend and makes local workflows usable. The optional API now enforces account-backed sessions, role permissions, CSRF/origin checks, strict input bounds, atomic persistence and failed-save rollback. The browser preview remains a demo. Campus SSO/MFA, shared transactional storage, CCTV, dispatch integrations, backups and monitored service health remain production deployment work. See [platform hardening](03-auth-and-session.md) for setup and practical limits.

## Verification

The redesign was checked in the in-app browser at desktop, tablet (767 CSS px), and mobile (390 CSS px) widths. Checks included light/dark presentation, navigation focus restoration, keyboard tabs, list/board and empty-state filters, snapshot loading, guard/analyst/admin access, case creation and reload, report save and reload, acknowledgement persistence, and shift-note persistence. Browser download feedback was verified; HTML generation, escaping, and download-anchor behavior are covered by the isolated workflow tests.

Run `npm run build`, `npm run lint`, `npm run test:operations`, `npm run test:api`, and `npm run test:resilience`. The legacy action-token smoke check also remains available. Illustrative sample snapshots are local SVG assets generated by `scripts/generate-demo-snapshots.mjs`; they are explicitly labeled and contain no real camera imagery.
